# Freqtrade 前端操作指南

本文档对应当前项目中的中文 FreqUI、策略档案、全局杠杆、自动做空和图表时间范围功能。

## 1. 先确认当前连接的机器人

页面右上角机器人菜单显示当前 API 实例。每个实例有自己的运行模式、交易所、策略和数据：

- `trade` / `dry_run`：交易机器人，图表跟随机器人实际运行的策略和周期。
- `webserver`：研究与历史图表实例，可以在图表页临时选择策略、K 线周期和日期范围。

页面显示“在线”只代表 API 可访问，不代表策略已经产生交易信号。

## 2. 图表页

### 策略

- 交易模式下策略选择器为灰色，这是安全限制；标题中的策略名就是机器人实际运行的策略。
- Webserver 模式下可以选择已批准的 `SampleStrategy`、`CryptoTrendBreakoutStrategy` 或 `CryptoTrendBreakoutLongShortStrategy`。
- 图表中的策略选择只用于计算历史指标和信号，不会修改交易机器人。

### 时间周期

- 交易模式下周期选择器为灰色，图表只能显示机器人当前周期；当前策略实际运行周期为 `5m`。
- Webserver 模式下可以选择 `1m`、`3m`、`5m`、`15m`、`30m`、`1h` 查看历史图表。
- 图表周期与真实交易周期是两个概念。切换历史图表周期不会让正在运行的机器人热切换周期。

### 开始日期和结束日期

- 日期格式为 `YYYY-MM-DD`。
- 只填写开始日期表示从该日到最新可用数据。
- 同时填写开始和结束日期表示固定区间。
- 结束日期必须晚于或等于开始日期，并且不能超过已经下载或交易所可返回的数据范围。
- 修改日期后点击“刷新图表”。日期可以选择但周期为灰色，通常说明当前连接的是交易实例，不是 Webserver 实例。

### 没有图表或信号

依次检查：

1. 右上角机器人是否在线。
2. 交易对是否在当前白名单或历史数据列表中。
3. 所选周期和日期是否有 K 线数据。
4. `/api/v1/pair_candles` 或历史图表请求是否成功。
5. 指标条件是否真的满足。没有买卖点不等于没有 K 线数据。

## 3. 策略运行时设置

策略运行时设置用于安全地切换已批准档案。系统会先预览，再应用，并请求机器人重载。

- 有未平仓交易或未完成订单时禁止切换。
- 当前只允许真实运行周期 `5m`。
- 现货档案不允许开启做空或大于 1 倍的杠杆。
- 多空档案要求 `futures + isolated`，不能应用到现货机器人。
- 应用后前端会轮询重载结果；若重载失败，后端会恢复之前的运行时档案。

生产交易前必须先完成回测和 dry-run。策略档案切换不是收益保证，也不应在持仓期间通过修改文件绕过保护。

## 4. 全局杠杆

全局杠杆控件只在期货机器人中显示：

- 只影响之后新开的仓位，已有仓位不变。
- 最终值仍会受交易所单交易对最大杠杆限制。
- 状态页直接调整是运行时设置；机器人重启后以配置文件或运行时档案为准。
- 推荐从逐仓 `2x` dry-run 开始。杠杆越高，手续费、资金费率和强平风险越明显。

## 5. 自动做空

自动做空开关只在期货模式显示：

- 关闭后阻止新的自动空单信号。
- 已有空仓不会立即平仓，仍按策略退出规则管理。
- 手动强制下单属于独立操作，不应把自动做空开关当作账户级权限控制。

## 6. 独立 Webserver 的启动方式

普通 `docker compose up -d` 只启动交易容器。需要研究模式时显式执行：

```bash
docker compose --profile research up -d freqtrade-webserver
```

该服务只监听服务器本机 `127.0.0.1:8081`。需要在前端使用时，通过现有 HTTPS 反向代理为它配置独立、受认证保护的入口，然后在 FreqUI 中添加为第二个机器人。不要直接向公网开放 8081。

停止研究实例不会影响交易容器：

```bash
docker compose --profile research stop freqtrade-webserver
```

## 7. 常见状态码

- `200`：请求成功。
- `401`：登录状态或 API 凭据无效。
- `409`：配置不兼容、存在持仓/挂单，或机器人正在重载。
- `422`：周期、杠杆、做空开关或其他参数不符合策略约束。
- `500`：后端内部错误，需要查看容器日志。
- `503`：交易所服务不可用，常见原因是服务器网络、地区限制、代理、API Key 权限或现货/合约模式不匹配。

查看最近日志：

```bash
docker compose logs --tail=200 freqtrade
docker compose logs --tail=200 freqtrade-webserver
```
